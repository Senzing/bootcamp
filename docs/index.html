Curriculum

What the bootcamp covers

Hands-on modules, in order, from zero to working entity resolution.

  1. Bootcamp preparation Choose your curriculum, level of detail and programming language.
  2. Entity resolution concepts Optional A primer on how entity resolution works.
  3. Discover the business problem Describe the problem you are trying to solve.
  4. SDK setup Install and configure the Senzing SDK.
  5. System verification Optional End-to-end checks that Senzing works on your machine.
  6. Truth Set visualization Optional An interactive web app of the resolved Truth Set data.
  7. Data collection Identify and collect your data sources.
  8. Data quality, mapping and transformation Make your data “Senzing-ready”.
  9. Data processing Ingest your Senzing-ready data.
  10. Query, visualize and discover See what Senzing can do for you.
  11. Bootcamp graduation Wrap up your bootcamp with a bow.

  • A production starter

    A production/ starter project to build on.

Before you start

Requirements

  • Required Network access to the Senzing MCP server. It generates SDK code, looks up Senzing facts and provides working examples. The bootcamp cannot proceed without it.
  • Required A plan on your platform. Each platform’s minimum is listed below.
  • Recommended A business problem and 5,000 to 20,000 records. Bring a problem that needs entity resolution and data that illustrates it. Recommended, but not mandatory.
